# 📊 E-Commerce Sales Performance Dashboard | Power BI

📌 Project Overview

This project presents an interactive E-commerce Sales Performance Dashboard developed using Microsoft Power BI to analyze sales performance, revenue trends, product performance, and geographical sales distribution.

The dashboard transforms raw e-commerce data into meaningful business insights through interactive visualizations and KPI indicators.

🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Monitor total revenue and order volume.
- Identify top-performing products.
- Compare revenue across product categories.
- Analyze city-wise sales performance.
- Understand pricing and revenue patterns.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

📈 Key Performance Indicators (KPIs)

The dashboard includes:

- Total Revenue: 6.16M
- Total Orders: 1K
- Total Quantity: 2K
- Top Product Revenue: 838K
- Average Order Value: 6.16K

Figures represent the displayed dashboard values.

📊 Dashboard Features

1. Revenue Analysis
Analyzes revenue generated across different product categories.

2. Category Performance
Compares sales contributions from Clothing, Electronics, and Groceries.

3. Top-Selling Products
Identifies products generating the highest revenue.

4. City-wise Performance
Visualizes sales performance across different cities.

5. Price vs Revenue Analysis
Explores the relationship between product prices and revenue.
